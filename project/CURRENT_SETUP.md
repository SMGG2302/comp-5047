# 当前固件与接线（2026-10-28，v4）

ESP32-WROOM-32 连接路由器的 2.4GHz Wi-Fi，电脑留在同一局域网。
凭据在本机 `firmware/main/wifi_credentials.h`，该文件被 Git 忽略。
其他机器从 `wifi_credentials.example.h` 复制并填写。不得将真实密码提交到仓库。

| 模块 | 信号接口 |
| --- | --- |
| SHT3x | SDA GPIO21，SCL GPIO22 |
| 导水布左一电容传感器 | AO GPIO34 |
| 导水布左二电容传感器 | AO GPIO36（VP） |
| 光照 | AO GPIO39（VN/SVN） |
| 水位 | AO GPIO32 |
| MG90S 水阀 | 信号 GPIO13，外部5V供电并共地 |
| SEN0487 | AO GPIO33 |
| VL53L0X | SDA GPIO27，SCL GPIO26 |

模拟输入电压须在0–3.3V。DS18B20禁用。

- 当前为光照单条件测试：有效光照ADC<500开阀至1200μs，≥500或光照无效时关阀至2500μs；上电关闭。
- 每100ms改变10μs，完整动作约13秒，始终输出50Hz PWM。阀门状态表示输出命令，不是机械位置测量。
- 湿度<2000为湿润，≥2300为干燥，中间保持此前状态；初始中间值或无效采样为未知。
- 输出达到1200μs后开始开阀计时；满60000ms后任一导水布仍干燥即产生堵塞告警。关闭阀门重置计时。未知读数不算干燥。
- 光照<500判为太阳直射。水位<50提示“小于50ml”和补水维护。水位数值为ADC，标签为用户标定规则，不作连续体积换算。
- 温度、水位暂不参与开关阀判断；水位仍用于维护告警。

本机执行 `website/HollowHaven.cmd`，网页地址为 http://127.0.0.1:8766。
设备地址填写 `auto`，通过UDP9002发现设备，然后TCP9000收取v4遥测，TCP9001收取音频。
发现失败时可填写串口打印的DHCP IPv4地址。路由器不得开启客户端隔离。
v4增加第二路湿度、两路湿润状态、阀门状态、脉宽、开阀毫秒数和堵塞告警。

编译/烧录使用 `firmware/build-ascii.ps1 -Upload -Port COM3`。
旧README中的热点和舵机往返试调描述是历史记录，以本文件为准。
