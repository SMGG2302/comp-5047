CONNECTION & INTELLIGENCE

连接你的树屋

设备接收与云端分析分别配置，录音始终留有本地副本。

01 / 设备

ESP32 热点连接

HollowHaven-ESP32

在 Windows 的 Wi-Fi 列表连接这个热点，再回到实时监测点击连接。

传感器端口 9000 · 音频端口 9001
暂不支持蓝牙接收。

离线接收，联网识别

只有一张无线网卡时：先接收录音 → 暂停设备连接 → 切回能上网的 Wi-Fi → 上传识别。若有以太网或第二张网卡，可同时使用。

02 / 识别

音频分析 API

POST原始WAV，Bearer鉴权；返回 [{label,score}] 或 {label,evidence,uncertainty}。其他接口格式需适配。

尚未配置密钥

候选类别作为 Gemini 分析背景；自定义模型使用其自身标签。通用音频模型不保证区分具体物种。
