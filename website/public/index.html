CONNECTION & INTELLIGENCE

连接你的树屋

设备接收与云端分析分别配置，录音始终留有本地副本。

01 / 设备

路由器局域网连接

固件中配置的路由器

ESP32 上电后自动连接路由器。电脑连接同一局域网即可接收，同时保留互联网连接。

ESP32 使用2.4GHz；电脑可用同一路由器的5GHz。请关闭客户端隔离。
传感器 TCP 9000 · 音频 TCP 9001 · 发现 UDP 9002

自动发现失败时，填写 ESP32 串口输出的 IP。

本机网页，联网识别

网页服务运行在本机8766端口，无需切换 ESP32 热点。

02 / 识别

音频分析 API

POST原始WAV，Bearer鉴权；返回 [{label,score}] 或 {label,evidence,uncertainty}。其他接口格式需适配。

尚未配置密钥

候选类别作为 Gemini 分析背景；自定义模型使用其自身标签。通用音频模型不保证区分具体物种。
