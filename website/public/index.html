01 / DEVICE

Router / local network

Router configured in the firmware

ESP32 connects to its configured router at startup. Keep this computer on the same LAN to receive data and retain internet access.

ESP32 requires 2.4 GHz Wi-Fi. Your computer can use the same router’s 5 GHz network. Disable client isolation.
Sensors TCP 9000 · Audio TCP 9001 · Discovery UDP 9002

If discovery fails, enter the IP printed in the ESP32 serial monitor.

Local dashboard, online analysis

The dashboard runs locally on port 8766. No ESP32 hotspot switching is needed.
